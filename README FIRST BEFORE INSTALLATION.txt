AERIUM 1.1.1
README FIRST BEFORE INSTALLATION
TonePixels Studio

Please read this before installing Aerium on your Mac.

1. BEFORE YOU BEGIN

• Close your recording software before running the installer.
• Aerium is provided as a macOS package (.pkg) for Apple Silicon and Intel Macs.
• Download the installer only from the official Aerium release source.

2. INSTALL AERIUM

1. Open Aerium-1.1.1-macOS.pkg.
2. Follow the installer instructions.
3. Select VST3, Audio Unit (AU), or both on the Customise screen. Both are selected by default.
4. Complete the installation, then reopen your recording software. Rescan plugins if Aerium does not appear immediately.

3. IF macOS BLOCKS THE INSTALLER

Aerium 1.1.1 is unsigned and has not been notarised by Apple. macOS may display a security warning.

1. Try opening the installer normally first.
2. If macOS blocks it, open System Settings > Privacy & Security.
3. In the Security section, select Open Anyway for the Aerium installer if that option appears.
4. Confirm only if you trust the download source, then continue installation.

Do not disable Gatekeeper or change system-wide security settings.

4. WHERE YOUR FILES GO

Aerium keeps its user-accessible content in:

~/Documents/Aerium/

Inside, you will find Microphone IRs, Factory Presets, Presets, EQ Profiles, Tone Match Profiles, and Aerium User Manual.pdf.

The installer places the plugin formats in the normal macOS locations; you do not need to move the plugin bundles manually.

5. IF AERIUM CANNOT ACCESS DOCUMENTS

If your recording software requests permission to access Documents, allow it if you trust the software.

If Aerium reports a Documents access error, close the recording software and check System Settings > Privacy & Security > Files and Folders. If your recording software is listed with a Documents Folder permission, enable it and try again.

A missing-file or installation-permissions problem is different from a macOS privacy prompt. If the warning remains, use the latest corrected Aerium installer and report the exact message; do not change unrelated security settings.

6. FIND AERIUM IN YOUR RECORDING SOFTWARE

Choose the installed VST3 or Audio Unit plugin named Aerium. If it is missing, restart your recording software and run its plugin rescan. Consult the included Aerium User Manual.pdf for controls, presets, microphone IRs and Tone Match.

Aerium is free to use. Thank you for making music with Aerium.
